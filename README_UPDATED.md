# PIO Website — Full White/Green Brand Experience

This version expands the existing PIO Vite/React website into a fuller brand site inspired by the supplied visual direction.

## Implemented
- Bright white + PIO green visual system
- 240-frame scroll-driven hero retained and refined
- New hero copy: Small Sip / Big Refreshment / ₹10
- Responsive navigation: Home, Flavours, Why PIO, Our Story, Where to Buy, Contact
- Our Flavours cards for Mango and Lychee
- Why PIO benefit section
- Mango Story + Lychee Story visual chapters
- Large ₹10 value section
- What's Inside / ingredient-quality cues
- SipOhh Moments section
- Where to Buy CTA section
- Redesigned animated Our Story section using the heritage visual
- Existing Partner and Contact functionality retained
- Framer Motion / GSAP / Lenis motion system
- Responsive desktop/tablet/mobile treatment
- Reduced-motion behavior retained

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
Publish the `dist` folder on Render/Vercel/static hosting.

Note: package installation could not be completed inside the artifact environment due to a tool/network timeout, so run `npm install` locally before building.
